# Codex 对话导出器

1. 双击 `打开导出器.cmd`。
2. 搜索标题中的关键词，例如 `SQL`，点击目标对话。列表优先显示 Codex 中的对话名称，无名称时显示首条提问。也可用会话 ID 搜索。
3. 可以在下方修改导出标题。点击“导出 Markdown…”，选择保存位置。

窗口会显示实际合并的日志片段数量和导出的消息数量。工具自动核对日志内的会话 ID，不会把文件名中带有相同父会话 ID 的子会话混进来。

默认隐藏 AI 子任务与已归档记录。勾选“显示 AI 子任务”或“显示已归档对话”可查看，类型列会标明来源；选择子任务时，下方显示所属对话。子任务是助手执行工作时产生的独立记录，通常不需要单独导出。

此工具仅在本机运行，无网络请求、无 AI 调用、无 token 消耗；以只读方式访问 Codex 索引和原始会话文件，只写入你选择的 Markdown 文件。关闭窗口即可退出，不运行后台服务。

导出会合并所选 Codex 数据目录中同一会话 ID 的现存日志片段，并保留用户、助手消息和助手的进度说明。过滤环境、技能注入、工具调用、工具输出及推理记录。图片和音视频附件不打包，只保留提示或链接。无法解析的日志行会明确写在导出文件末尾。

“合并完整”指本机现存、可识别的对话消息。被删除的日志、未同步的云端内容、其他电脑上的文件和其他会话 ID 不会凭空恢复。导出正在进行的对话时，仅覆盖读取时已写入磁盘的记录；需要最新回复时请等生成结束后再导出。

默认读取 `%USERPROFILE%\.codex`，或 `CODEX_HOME` 指定的目录。若使用隔离配置或其他安装，可点“更换数据目录”，选择包含 `state_*.sqlite` 和 `sessions` 的目录。

需要带 Tkinter 的 Python 3.10+。启动器优先使用当前电脑已有的 Codex 内置 Python；找不到时尝试系统 Python。三个文件保持在同一个文件夹内，可整体移动，或为 `打开导出器.cmd` 创建桌面快捷方式。
